Hobby project

A personal WhatsApp Web archiver that turns Instagram links into a floating reel player.

wa-notify captures new WhatsApp Web messages into a local SQLite database, spots Instagram reel and post links, fetches them politely and opens them in a small floating mpv window.

View on GitHub Read the docs

Heads up: built and tested on one Linux machine (Arch, Wayland, Hyprland). It relies on private, undocumented WhatsApp Web internals and can break whenever WhatsApp ships an update. Support is best effort.

How it works

  1. 1

    Capture

    A Manifest V3 browser extension hooks WhatsApp Web's in-page message store and queues each new message in the browser, so a restart does not lose it.

  2. 2

    Archive

    A small Node server on 127.0.0.1 stores messages in SQLite, deduplicated by message id, and extracts Instagram reel and post links.

  3. 3

    Watch

    Python tools alert you to fresh reels, fetch them one at a time with yt-dlp and open videos or photo posts in a floating mpv window.

Features

  • Local-first archive

    SQLite in WAL mode. Nothing leaves your machine except what you explicitly enable.

  • Live reel alerts

    Tells fresh messages from history loading, so scrolling an old chat does not flood you.

  • Floating player

    Reels and photo posts (single images and carousels) open in one pinned window. The browser is a last resort.

  • Polite fetch queue

    One request at a time, cool-downs after blocks, retries with backoff and per-reel locks.

  • Optional Instagram session

    Re-uses your browser's existing login through yt-dlp when anonymous access is rate-limited. Opt-in.

  • Optional AI summaries

    Short summaries through the Gemini API. This uploads the video to Google, so it stays off unless you set a key.

  • Launcher and digest

    A fuzzel menu for quick picks and an fzf digest with a preview pane.

  • Disk hygiene

    A daily timer removes cached media once a reel has been opened for a while.

Limitations and legal notes

  • It hooks undocumented WhatsApp Web internals and will break without notice.
  • Automating WhatsApp Web likely violates WhatsApp's terms of service. Use it for yourself only and at your own risk.
  • The archive holds other people's messages and media metadata. It is not encrypted at rest. Treat it as sensitive.
  • The local server authenticates with a trust-on-first-use token and listens on loopback only. There is no multi-user model.
  • Instagram may rate-limit anonymous downloads. The optional login reuses your session and carries some account risk.
  • Some values are hard-coded (default port, window class and size, launcher font). Only part of them is configurable yet.

The full lists live in docs/LIMITATIONS.md and docs/KNOWN_ISSUES.md.
